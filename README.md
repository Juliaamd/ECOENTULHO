# ECOENTULHO
Sistema web para gestão inteligente de resíduos da construção civil, com classificação automática, dashboard analítico e simulação de destinação ambiental, alinhado aos ODS 11 e 12 da ONU. O projeto aborda o problema do descarte irregular de entulho em Goiânia-GO e propõe uma solução digital educativa e de controle ambiental.
